# Wildlife-Reidentification

Re-identifying individual hyenas and leopards from precomputed MiewID descriptors and SIFT
keypoints (course Problem Statement 3), scored with MAP@5.

- Problem statement, rules and conventions: [CLAUDE.md](CLAUDE.md)
- Decision log: [docs/DECISIONS.md](docs/DECISIONS.md)
- Experiment log: [docs/EXPERIMENTS.md](docs/EXPERIMENTS.md)

Setup: unzip `projectwild3.zip` at the repo root so you get `projectwild3/` (git-ignored), then
`pip install -r requirements.txt`.
